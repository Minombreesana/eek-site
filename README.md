# EEK · Estación Espacial Kennedy

[estacionkennedy.space](https://estacionkennedy.space)

La Estación Espacial Kennedy (EEK) es un proyecto de investigación-creación ubicado en la localidad de Kennedy, Bogotá, Colombia. Se concibe como una declaración artística que desafía las nociones tradicionales de espacio y tecnología, situándose en el sur global, en una de las áreas marginadas de la ciudad. Utilizando la ficción y la simulación, este proyecto busca resignificar las nociones de espacio (sideral) y territorio mediante una apropiación simbólica.
